# MAKE OS

Kevins & Malins Life- und Business-System — Next.js 15, TypeScript, JSON-Bestände in `.data/`.

- **Arbeiten:** `CLAUDE.md` (Regeln, Architektur), `UPDATES.md` (was auf `entwicklung` fertig ist, was online ist)
- **Betrieb:** `DEPLOY.md` (Hetzner, Docker, Caddy, Sicherung, Härtung), `deploy/`
- **Lokal:** `./start.sh --entwicklung` (legt `.env.local` mit `MAKE_OS_KEY` und `SESSION_SECRET` an), dann http://localhost:3001

Das Repo enthält Code und Regeln — nie Daten (`.data`, `.env*` sind ausgeschlossen).
